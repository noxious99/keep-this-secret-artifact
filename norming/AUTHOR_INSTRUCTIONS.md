# Author rating sheet (cross-check for the label norming)

Each author works **alone**, before seeing any model score and without discussing the ratings with the other authors.

1. Copy `author_ratings_template.csv` to `author_ratings_<your initials>.csv`.
2. For each sentence, enter four whole numbers from 1 (not at all) to 7 (extremely):
   - **confidential_1to7**: how confidential or private is the number?
   - **important_1to7**: how important does the number sound?
   - **natural_1to7**: how natural does the sentence sound?
   - **typical_number_1to7**: how typical is it for this kind of thing to be a number?
3. Rate quickly, by first impression; do not go back to make ratings consistent.
4. Return the file. It is used only to report agreement with the model-based scores, never to select labels.
