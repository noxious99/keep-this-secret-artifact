# Keep This Secret: artifact

Code, frozen pre-registrations and all model answers for the paper *Keep This Secret: How Confidentiality Instructions
Reshape In-Context Secret Leakage*. Every number in the paper is computed from the files here by the scripts here.

## Layout

```
preregistration_*.md   frozen pre-registrations (S2, S2b, S3, S4, S5), each frozen before its data were collected
*.ipynb                notebooks that generated and scored every answer (run on Kaggle, 2x NVIDIA T4)
analysis/              notebook builders (build_nb_*.py), analysis scripts, the reanalysis plan (r0_plan.md)
                       and the S5 pilot plan (v7_pilot_plan.md)
norming/               label-norming protocols (rounds 1 and 2), candidate labels, the selected labels, and three
                       independent rater sheets (raters A, B, C)
results/               one folder per model and study with the raw answers, plus the analysis outputs (*.json)
```

## Data

Each run folder holds:
- `responses.jsonl`: one sampled answer per line, with its job id, value, decoy, condition and token ids;
- `scores.jsonl`: the answer's log-probability under the prompt with the value and with the decoy (total and per token);
- `greedy_single.jsonl`, `greedy_batched.jsonl`: greedy answers generated one at a time (the attacker's references)
  and in left-padded batches of 16 (the observed answers);
- `metadata.json`: model, checkpoint revision, library versions, run counts and the prompt hash.

The prompt hash printed by every run ties its answers to the frozen design: S2 `28d8e5ca2fa7`, S2b `69dfb319a3f2`,
S3 `aaa28951c574`, S4 `58b9866ce681`, S5 `5f62a0b3b4cf`.

## Reproducing the analyses (CPU, minutes)

```
pip install -r requirements.txt
python analysis/v4_analyze.py results/pilot_v4_qwen3-8b results/pilot_v4_qwen3-14b results/pilot_v4_qwen3-32b results/pilot_v4_llama
python analysis/v5_analyze.py results/pilot_v5_qwen3-32b results/pilot_v5_mistral-small-24b-instruct-2501
python analysis/v5b_analyze.py results/pilot_v5b_qwen3-32b results/pilot_v5b_mistral-small-24b-instruct-2501 --v5 results/pilot_v5_qwen3-32b results/pilot_v5_mistral-small-24b-instruct-2501
python analysis/v6_analyze.py results/pilot_v6_phi-4 results/pilot_v6_falcon3-10b-instruct results/pilot_v6_granite-33-8b-instruct results/pilot_v6_olmo-2-0325-32b-instruct results/pilot_v6_llama-31-8b-instruct
python analysis/attack_analyze.py
python analysis/r0_audit.py
python analysis/r0_nearest_ref.py
python analysis/v7_run.py
```

The pre-registered analysis scripts also run on synthetic data with planted and null effects: `--selftest`
(`attack_analyze.py`, `v7_analyze.py`, `norming_select.py`, `v7_pilot_analyze.py`).

## Regenerating the answers (GPU)

The notebooks run on Kaggle with two NVIDIA T4 GPUs, 4-bit NF4 weights and the checkpoints recorded in each
`metadata.json` (pinned revisions for S4 and S5). Each notebook is generated by `analysis/build_nb_*.py`; edit the
builder, not the notebook. `v4_reader_api.py` and `norming_api_ratings.py` call the DeepSeek API and read
`DEEPSEEK_API_KEY` from a `.env` file in the repository root (not included).
